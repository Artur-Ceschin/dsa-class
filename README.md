# Daily Algo

A collection of famous LeetCode problems solved in JavaScript and TypeScript.

## About

This project contains implementations of popular algorithm and data structure problems to help practice coding skills and prepare for technical interviews.

## Languages

- JavaScript
- TypeScript

## Running the Code

To run any problem solution:

```bash
node problems/<filename>.js
```

For example:
```bash
node problems/rotten-oranges-994.js
```
